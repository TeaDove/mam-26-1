# Лабораторная 2 — предобработка текста и сравнение графов знаний

Задание — в [TASK.md](TASK.md), работа над ошибками после защиты — в [TASK2.md](TASK2.md), конспект лекции — в
[predobrabotka.md](predobrabotka.md).

Два учебника по контролируемой прокатке стали — `tanaka1981` (английский обзор, 28 страниц) и `stat3`
(русская статья, 10 страниц) — вместе образуют один общий граф. Сравниваются два графа:

- **грязный** — GraphRAG по markdown MinerU, из которого удалён только список литературы;
- **чистый** — GraphRAG по тому же markdown после полной предобработки.

Настройки GraphRAG у обоих графов одинаковые: gpt-4o-mini, эмбеддинги bge-m3, те же промпты и типы сущностей,
окна 1200/100 токенов, кластеризация без ограничения на крупнейшую компоненту. Чистые чанки (≤ 1100 токенов)
GraphRAG не перерезает.

Презентация — [results/presentation.pptx](results/presentation.pptx), глоссарий с описанием алгоритмов —
[results/glossary.md](results/glossary.md).

## Пайплайн

```
грязный:  PDF → MinerU → без списка литературы → GraphRAG
чистый:   PDF → MinerU → без списка литературы → очистка → нормализация → chunking → токенизация → векторизация
          → GraphRAG
```

Очистка и нормализация работают с книгой целиком, chunking режет уже чистый текст. Качество этапов меряется на
эталоне — четырёх страницах, выверенных вручную по PDF (`data/gold/`). Отчёт с интерпретацией каждой метрики —
[results/preprocessing_report.md](results/preprocessing_report.md).

| Этап | Что делается | Главные метрики |
| --- | --- | --- |
| 1. Очистка | Колонтитулы, номера страниц, ссылки на картинки, HTML-сноски, маркеры цитат, шапка с авторами (PII); склейка абзацев, разорванных страницами и подписями; переносы; проверенные исправления OCR. Журнал — `data/01_clean_audit.jsonl`. | CER 9,7% → 0,2%, WER 14,4% → 2,0%; удалено 13 из 13 нужных блоков, лишних — 0 |
| 2. Нормализация | Величины (`730<sup>0</sup>С` → `730 °C`), аббревиатуры, двуязычный глоссарий «английский канон первым» (заново каждые 3000 символов), марки стали по составу, лемматизация терминов. Журнал — `data/02_normalized_audit.jsonl`. | Величин в едином виде 20% → 95%; эталон: величины 7/7, термины 10/10; общих терминов книг 0 → 23 |
| 3. Chunking | По разделам и абзацам до 900 токенов; формулы и таблицы не режутся; граница — на конце предложения. Чанки сохранены для RAG. | Границ, режущих предложение, 100% → 3%; разрезанных формул и таблиц 6 → 0 |
| 4. Токенизация | Слова, числа, формулы целиком; OOV по wordfreq и глоссарию. | OOV-rate 1,39% → 1,00%; обрывков формул 8 → 0 |
| 5. Векторизация | bge-m3 (1024) для чанков и вершин графа; TF-IDF на окнах по 300 слов; поиск по 26 вопросам. | MRR 0,59 → 0,77 (2 × 2: разбиение и предобработка дают примерно по +0,1) |

## Сравнение графов

Все критерии считаются по графу. Для вершины собирается окно обхода «2 в глубину × 3 в ширину»; LLM (gpt-4.1)
используется только для непротиворечивости. Отчёт с интерпретациями —
[results/graph_criteria_report.md](results/graph_criteria_report.md), данные —
[results/metrics/08_graph_comparison.json](results/metrics/08_graph_comparison.json).

| Критерий | Как считаем | грязный | чистый |
| --- | --- | --- | --- |
| Полнота по тексту | 180 терминов текста среди вершин: леммы или cos bge-m3 ≥ 0,8 | 53,9% | 60,6% |
| Непротиворечивость | окно BFS-2 + фрагмент текста → gpt-4.1, 120 вершин; доля вершин с противоречиями | 37,5% | 30,8% |
| Корреференции | вершин в группах дубликатов по леммам; пар по cos названий ≥ 0,92; местоимений | 17; 8; 0 | 40; 13; 0 |
| Шум | 5 регулярных правил + словарь по всем вершинам | 5,2% | 7,5% |
| Целостность формул и таблиц | обозначения формулы целыми токенами в вершине / окне 2 × 3 | 0 из 12 целы | 0 из 12 целы |
| Показатели графа | вершины / рёбра; крупнейшая компонента; циклы E − V + C | 324 / 336; 55%; 74 | 424 / 437; 66%; 97 |
| Покрытие ПрО (40 понятий) | по названиям / по векторам вершин | 77,5% / 57,5% | 92,5% / 65% |
| Обходы | связанные пары среди пар, где оба понятия есть в графе; доля вершин русской книги в BFS-2 | 3 из 6; 8% | 8 из 10; 20% |
| Вершины и рёбра по типам | типов вершин; пар типов у рёбер | 13; 54 | 12; 59 |

Выводы:

- Предобработка приблизила русскую книгу к английской: русских вершин в крупнейшей компоненте 7 из 87 → 21 из 89,
  покрытие ПрО и полнота выросли. Связь частичная: прямых рёбер между языками нет ни в одном графе.
- Непротиворечивость — разница в пределах погрешности (стандартная ошибка около 6 п. п. при 120 вершинах).
- Шум вырос: из целых формул модель сделала вершины-обозначения (`Σ_{LH}`, `N_S`); опечатки модели — на том же уровне.
- Дубликатов больше: модель пишет одно понятие в ед. и мн. числе — нужна склейка вершин после извлечения.
- Формулы и таблица не сохраняются ни в одном графе — ограничение GraphRAG.
- Чистый текст пришёл более мелкими чанками: 17 вершин на 1000 токенов против 10, поэтому часть роста графа — эффект
  разбиения, а не очистки.

## Запуск

Нужны Python 3.14 и `uv`. Эмбеддинги — локальный сервер bge-m3 с OpenAI-совместимым API (`LAB2_EMBEDDING_URL`),
LLM — OpenAI-совместимый API (`LAB2_OPENAI_BASE_URL`, ключ — `LAB2_OPENAI_API_KEY` или stdin). Графы строит
GraphRAG с настройками из `graphrag-dirty/settings.yaml` и `graphrag-clean/settings.yaml`; ключ
`scripts/run_index_both.sh` читает из stdin.

```bash
uv sync
uv run lab2 prepare     # markdown MinerU без списка литературы → data/00_dirty (вход грязного графа)
uv run lab2 clean       # 1. очистка книги целиком
uv run lab2 normalize   # 2. нормализация и лемматизация терминов
uv run lab2 chunk       # 3. структурный chunking
uv run lab2 tokenize    # 4. токенизация
uv run lab2 vectorize   # 5. векторизация
uv run lab2 gold        # оценка очистки и нормализации на эталонных страницах
uv run lab2 retrieval   # Hit@k, MRR, NDCG@10
uv run lab2 export      # входы GraphRAG: graphrag-dirty/input и graphrag-clean/input
scripts/run_index_both.sh   # индексация GraphRAG обоих графов
uv run lab2 graphs      # графы с векторами вершин → results/graphs
uv run lab2 compare     # критерии сравнения обходами графа и судья
uv run lab2 figures     # картинки графов
uv run --with pyvis python scripts/build_html_graphs.py   # интерактивные HTML-графы
uv run python scripts/build_presentation.py
uv run pytest && uv run ruff check . && uv run ruff format --check .
```

Метрики первой версии (до работы над ошибками) — в `results/v1/`.
