# Задание 2

Провести полный цикл предобработки. Сравнить граф, полученный без предобработки,
с графом, полученным с предобработкой:

- полнота по тексту;
- непротиворечивость по тексту;
- корреференции;
- шум — несмысловые символы;
- целостность: формул, таблиц и т. д.;
- показатели графа: компонента связности, мосты, степени свободы, циклы;
- покрытие ПрО;
- количественные показатели: вершины, рёбра по типам.

По результатам сделать презентацию на 5–7 минут.

Источник задания — лекция «Предобработка», конспект в [predobrabotka.md](predobrabotka.md).

## Уточнения преподавателя

Главная цель — получить два графа, «грязный» и «чистый», и сравнить и оценить их с помощью
алгоритмов обхода графа.

- **Корпус.** Оба учебника участвуют в построении одного общего графа, а не графа по каждому
  учебнику отдельно. Презентация тоже по двум учебникам.
- **Граф без предобработки** — GraphRAG на сыром тексте, из [../lab-1](../lab-1).
- **Граф с предобработкой** строится тоже из текста, только предобработанного: через
  GraphRAG или готовый сервис построения графов (например, Wikontic), а не своим кодом.
- **Этапы предобработки:** chunking → очистка → нормализация → токенизация → векторизация,
  без аугментации.
- **Chunking** выполнить и сохранить результат: он понадобится на следующем этапе, в RAG.
- **Векторизация** — главный этап предобработки, без неё RAG не сделать. Векторы кладутся
  атрибутами в вершины графа.
- **Проверка качества после каждого этапа:**
  - chunking — средний размер блока, доля разорванных предложений и формул;
  - очистка — сохранность чисел, таблиц и формул, отсутствие PII и оставшихся служебных меток;
  - нормализация — доля изменённых терминов, корректность дат и единиц измерения;
  - токенизация — OOV-rate, целостность формул;
  - векторизация — размер словаря, разреженность.
- **Сравнение графов** — по критериям выше, с помощью LLM-as-a-judge и метрик графа,
  посчитанных алгоритмами обхода.
