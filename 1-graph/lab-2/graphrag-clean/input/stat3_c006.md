Накопленный опыт эксплуатации установка УОВТ на стан 3600 позволил на основании многофакторного корреляционно–регрессионного анализа выборки ДТУ лист (300 экспериментов с лист толщина 10–32 мм, около 40 плавок) разработать интегральную теплотехническая модель процесс accelerated cooling (ускоренное охлаждение) на установка:

$$
\boldsymbol {G} _ {\theta} \left[ \mathrm{M} ^ {3} / \text {час} \right] = 870 - 1076 \left(\mathrm{T} _ {3 \mathrm{cpm}} - \mathrm{T} _ {\mathrm{c}}\right) / \left(\mathrm{T} _ {0} - \mathrm{T} _ {\mathrm{c}}\right) + 6,65 (S - 1) \delta + 0,164 G _ {\mathrm{H}}, \text {где}
$$

$G_{o},G_{n} \mathrm{—}\ \mathrm{pax} \mathrm{o} \mathrm{\mu} \mathrm{b}$ вода соответственно на верхние и нижние охлаждающие устройство;

$\mathbf { T _ { 0 }, \Delta T _ { 3 \mathrm { \scriptsize ~ c p M } } }$ и Тс — соответственно температура начало охлаждение раскат, заданная среднемассовая и охлаждающей среды $\mathrm{(BO\_LII),~^{0}C}$

S — значение шкалы сельсинового команд–аппарата (сельсин);

— толщина охлаждаемого раскат, мм.

Разработанная модель позволяет по заданным технологический параметр установка $( S, \mathrm { ~ T _ c, ~ G _ { \mathrm { _ H } } } )$ , входной параметр раскат $( \mathrm { T } _ { 0 } \;, \; \delta )$ и заданной среднемассовая температура $( \mathrm { T } _ { 3 \mathrm { \Large ~ \tt ~ c p M } } )$ , задаваемой исходя из необходимый комплекс механическое свойство охлаждаемого проката, рассчитать расход вода на верхние охлаждающие устройство $( G _ { \mathrm { { B } } } )$ , обеспечивающий получение $\mathrm { T } _ { \mathrm { 3 \; c p w } }$ и оценить технологические возможности установка УОВТ при использовании ее в процесс КПУО (рис.2).

Проведенный анализ, показал преимущество применение в условиях стан 3600 для лист из low-pearlite steel (малоперлитная сталь) схема высокотемпературной КП (730–800 °C) с последующим ускоренное охлаждение, что повышает темп прокатка до 20% в сравнении с низкотемпературной КП (690–740 °C)
