Рис. 2. Зависимость среднемассовой cooling rate (скорости охлаждения) на установке accelerated cooling unit (УОВТ) раскатов толщиной 18,7 мм от температуры То до 500 °C при различных расходах воды: Цифрами около кривых указан расход воды на верхние охлаждающие устройства в м³/ч

На рис.2 приведены результаты расчета среднемассовой скорости охлаждения листов толщиной 18,7 мм от температур 800–730 °C по 500 °C при различных расходах воды на верхние $( G _ { \mathrm { { B } } } )$ и постоянном расходе на нижние $( G _ { \mathrm { H } }$ 1500 м³/ч охлаждающие устройства. Из приведенных результатов видно, что скорости охлаждения достигаемые на установке УОВТ в температурном интервале процесса controlled rolling with accelerated cooling (КПУО, контролируемая прокатка с ускоренным охлаждением) соответствуют сформулированным выше требованиям по скорости и длительности охлаждения.

Проведенный анализ, показал преимущество применения в условиях mill (стана) 3600 для листов из low-pearlite steel (малоперлитных сталей) схемы высокотемпературной КП (730–800 °C) с последующим accelerated cooling (ускоренным охлаждением), что повышает темп прокатки до 20% в сравнении с низкотемпературной КП (690–740 °C)
