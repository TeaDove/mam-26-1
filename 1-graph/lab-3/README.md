# Лабораторная 3 (ДЗ-2) — RAG на графе знаний с графовой нейронной сетью

Задание и принятые решения — [TASK.md](TASK.md). Графы знаний — из [лабы 2](../lab-2): грязный и чистый граф GraphRAG
по двум учебникам о контролируемой прокатке стали (`tanaka1981` EN, `stat3` RU).

## Архитектура

```
вопрос (RU/EN) → граф запроса (Qwen2.5-14B, промпт в стиле GraphRAG)
              → поиск: GNN-эмбеддинги вершин запроса и графа знаний, top-5 по косинусу, бонус за совпадение связей
              → контекст: 3 стартовые вершины + окрестность до 30 вершин, рёбра между ними,
                2 исходных фрагмента текста стартовых вершин
              → промпт «отвечай только по контексту» → ответ Qwen2.5-14B → судья Qwen2.5-14B по эталону
```

- Признаки вершин — bge-m3 (1024) от «название: описание».
- GNN — GAT (2 слоя, 8 голов, скрытый слой 64, dropout 0,3, ELU), задача — предсказание связей: рёбра делятся
  80/10/10, отрицательные пары сэмплируются, ранняя остановка по ROC-AUC на валидации. Для сравнения — GraphSAGE.
  Каждая модель обучена с 5 сидами, эмбеддинги усредняются.
- Узлы запроса получают эмбеддинги той же GNN индуктивно: признаки bge-m3 и рёбра графа запроса.
- Способы поиска: `bge-m3` — косинус исходных признаков без GNN (базовая линия); `gat`, `sage` — только эмбеддинги
  GNN; `hybrid` — основной: bge-m3 с весом 0,7 и GAT с весом 0,3.
- LLM, судья и эмбеддинги — локально на видеокарте рабочего ПК (Ollama, sentence-transformers), без платных API.

## Данные и метрики

- 26 вопросов (16 на английском, 10 на русском) с эталонными ответами по тексту — `configs/questions.yaml`.
- **Правильность ответа** — доля ответов, которые судья признал правильными (порог задания — 60%); «правильно или
  частично» — для справки.
- **MRR, Hit@k, context recall** — ранг первой релевантной вершины; релевантна вершина, извлечённая из фрагмента
  текста, где есть ответ (фрагмент совпал со всеми регулярками `evidence`).
- **Факт в графе / в контексте** — есть ли ключевой факт эталона (регулярка `key`) в описаниях вершин и рёбер всего
  графа / в контексте, отданном LLM.

| --- | --- | --- | --- |
| грязный | GAT | 0,775 ± 0,060 | 0,795 ± 0,041 |
| грязный | GraphSAGE | 0,775 ± 0,060 | 0,615 ± 0,131 |
| чистый | GAT | 0,815 ± 0,017 | 0,723 ± 0,040 |
| чистый | GraphSAGE | 0,815 ± 0,017 | 0,605 ± 0,081 |

| Граф | Поиск | MRR | Hit@10 | Факт в графе | Факт в контексте | Правильно | Правильно или частично |
| --- | --- | --- | --- | --- | --- | --- | --- |
| грязный | bge-m3 | 0,602 | 0,85 | 31% | 38% | 35% | 50% |
| грязный | GAT | 0,278 | 0,65 | 31% | 35% | 31% | 38% |
| грязный | GraphSAGE | 0,348 | 0,65 | 31% | 50% | 42% | 46% |

Ручная проверка 52 ответов на чистом графе (`results/manual_check.json`): с судьёй совпадает флаг «правильно» в 51
случае из 52. По ручной проверке bge-m3 — 65% правильных, гибрид — 42%.

## Выводы

1. **Порог 60% проходит только поиск без GNN на чистом графе** (62%, по ручной проверке 65%). Основной вариант с GNN
   (гибрид) даёт 42% на чистом и 46% на грязном графе.
2. **На маленьком графе GNN не добавляет пользы к сильным текстовым признакам.** 300–400 вершин и ~1 ребро на
   вершину: GAT предсказывает связи не лучше косинуса bge-m3 (0,72 против 0,82 на чистом графе), а проекция
   1024 → 64, обученная на нескольких сотнях рёбер, теряет смысловую близость. Чистые GAT и GraphSAGE ищут хуже
   базовой линии по всем метрикам; GraphSAGE к тому же нестабилен (разброс по сидам ±0,13).
3. **На грязном графе гибрид помогает:** факт попадает в контекст в 58% вопросов против 38% у bge-m3, правильных
   ответов 46% против 35%. Там описания вершин беднее, и связи графа добавляют информацию; на чистом графе
   описания уже хорошие, и вклад GNN только сдвигает стартовые вершины.
4. **Предобработка из лабы 2 окупилась:** ключевой факт эталона есть в описаниях чистого графа у 54% вопросов,
   грязного — у 31%; с поиском bge-m3 правильных ответов 62% против 35%.
5. **Граф сам по себе теряет числа.** В первом прогоне контекст состоял только из вершин и рёбер — не больше 27%
   правильных ответов (`results/graph_only_v1/`): GraphRAG при извлечении выбрасывает «730–800 °C», «5+3»,
   «10–30 °C/с». Исходные фрагменты текста стартовых вершин (атрибут вершины, как в local search GraphRAG) подняли
   результат до 62%.
6. Если факт есть в контексте, Qwen2.5-14B обычно отвечает правильно; если нет — честно пишет «нет ответа».
   Типичные ошибки — общие слова вместо конкретного факта и подмена этапа процесса (f06: «финишная прокатка»
   вместо «стадии 2»).

## Как шла работа

1. Контекст только из графа, GNN с одним сидом: правильных не больше 27%, GNN хуже bge-m3 и зависит от сида.
2. Две поправки (`TASK.md`, раздел 6): исходный текст стартовых вершин в контексте и гибридный поиск с усреднением
   GNN по 5 сидам.
3. Найден и исправлен источник невоспроизводимости: порядок связей в промпте зависел от рандомизации хешей Python,
   промпт менялся от запуска к запуску. Теперь связи идут в порядке вершин контекста, и все ответы пересчитаны.

## Запуск

Нужны Python 3.12, `uv`, видеокарта для bge-m3 и Ollama с `qwen2.5:14b-instruct` (адрес — `LAB3_LLM_BASE_URL`).
Если Ollama занимает видеопамять, этап `rag` запускается с `LAB3_DEVICE=cpu`.

```bash
uv sync
uv run lab3 features   # bge-m3 признаки вершин обоих графов → data/*_features.npy
uv run lab3 train      # GAT и GraphSAGE, 5 сидов, предсказание связей → results/metrics/link_prediction.json
uv run lab3 queries    # графы запросов → results/query_graphs.json
uv run lab3 rag        # поиск, ответ, судья для 2 графов × 4 способов → results/answers, results/metrics/rag.*
uv run lab3 ask "Какой элемент замедляет рекристаллизацию аустенита?" --graph clean --retriever hybrid
uv run python scripts/build_presentation.py
uv run pytest && uv run ruff check . && uv run ruff format --check .
```

Обучение GNN на CPU не воспроизводится бит в бит (недетерминированная агрегация в PyTorch Geometric), поэтому
результаты в таблицах получены на моделях одного запуска `train`; метрики обучения усреднены по сидам.

## Ограничения

- 26 вопросов: разница в 1 ответ — это 4 п. п.
- Судья — та же модель, что отвечает; ручная проверка сделана только для чистого графа.
- Вес гибрида 0,3 выбран до прогона; другие веса (0,1–0,2) офлайн тоже не обгоняли bge-m3 на чистом графе.
