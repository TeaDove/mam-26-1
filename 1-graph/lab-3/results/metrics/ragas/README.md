# Результаты лабораторной работы № 3

Сравниваем bge-m3, GAT, GraphSAGE и гибрид bge-m3 + GAT на двух графах знаний. В каждом варианте одни и те же
26 вопросов с эталонными ответами. Гибрид дал по 17 полностью верных ответов на обоих графах. У bge-m3
8 верных ответов на грязном графе и 16 на чистом.

## Исходные данные и воспроизведение

Обучение и генерация ответов описаны в [отчёте лабораторной № 3](../../../README.md). Скрипты читают сохранённые
ответы и исходные индексы GraphRAG лабораторной № 2. Для расчётов использовалась версия `d52c0f4`.

Выполните команды из каталога `1-graph/lab-3`. Для запуска используйте Python 3.12 и uv.

```bash
LAB3_DIR="$PWD"
uv run --no-project --python 3.12 \
  --with 'ragas==0.4.3' --with 'langchain-community==0.4.1' \
  --with 'openai==2.54.0' --with pandas --with pyarrow --with pyyaml --with typer --with loguru \
  python scripts/ragas_eval.py run --lab "$LAB3_DIR" --output ragas_recomputed.json
cmp results/metrics/ragas/ragas_scores.json ragas_recomputed.json
```

## Оценка по ID

Фрагмент входит в эталон, если он относится к заданному источнику и соответствует всем шаблонам фактов для
вопроса. Точность — доля найденных ID в эталоне. Полнота — доля эталонных ID, которые удалось найти. Для обоих
показателей считаем среднее по вопросам. В каждом варианте для всех 26 вопросов были и найденные, и эталонные ID.

Метрики сравнивают целые фрагменты. Точное положение факта внутри фрагмента и описания из подграфа
остаются за пределами этой оценки. Регулярное выражение может совпасть с лишним текстом или пропустить
перефразированный факт. Сравнивайте способы поиска внутри одного графа, поскольку индексы разбивают текст
на разные фрагменты. Для порога 60% используется доля полностью верных ответов по судье Qwen2.5-14B.

- [Точность Ragas по ID](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_precision/#id-based-context-precision)
- [Полнота Ragas по ID](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_recall/#id-basedcontext-recall)

## Смысловая оценка

Смысловые метрики Ragas 0.4.3 посчитаны для bge-m3 и гибрида на обоих графах. Судья — локальная
Qwen2.5-7B-Instruct в квантовании Q4_K_M с температурой 0. Скрипт собирает контекст каждого ответа
исходным форматтером лабораторной № 3 и записывает контрольную сумму SHA-256.

Задайте `OLLAMA_API_BASE` как базовый адрес OpenAI-совместимого API локального Ollama. Запустите
`qwen2.5:7b-instruct` с окном контекста не меньше 16 384 токенов. Затем выполните команду из каталога лабораторной.

```bash
PYTHONPATH="$LAB3_DIR/src" uv run --no-project --python 3.12 \
  --with 'ragas==0.4.3' --with 'langchain-community==0.4.1' \
  --with 'openai==2.54.0' --with networkx --with numpy --with pandas --with pyarrow \
  --with typer --with loguru \
  python scripts/ragas_semantic.py run --lab "$LAB3_DIR" --output semantic_recomputed.jsonl \
  --base-url "$OLLAMA_API_BASE" --model qwen2.5:7b-instruct --workers 2
```

Для продолжения прерванного прогона используйте тот же файл вывода. Полнота контекста (Context Recall)
оценивает долю эталонных утверждений, которые подтверждает контекст. Подтверждённость (Faithfulness)
оценивает долю подтверждённых утверждений ответа. Оба показателя усредняются по вопросам. Из средней
подтверждённости исключаются явные отказы и ответы без оценки утверждений. Поэтому важно сравнивать и само
значение, и число ответов, по которым оно рассчитано. Оценки модели могут варьироваться между средами исполнения.

- [Полнота контекста Ragas](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_recall/)
- [Подтверждённость ответа Ragas](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/)
